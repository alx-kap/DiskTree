Trash & History

Undo anything

DiskTree never deletes outright. Every item goes to the Trash and is logged, so you can put it back where it was. Empty the Trash right from the app when you're sure.

Get it in
a minute.

Three ways in. All free, all the same app. Requires macOS 14 Sonoma or later, on Apple silicon or Intel.

1

Download it

Unzip, drag DiskTree to Applications, then right-click it and choose Open the first time.

DiskTree.zip
2

One line

Paste into Terminal. It installs the latest release to ~/Applications and opens it, with no security prompt.

$ curl -fsSL https://alx-kap.github.io/DiskTree/install.sh | bash
3

Build it yourself

Needs Swift 5.9+ from Xcode or the Command Line Tools. No dependencies.

git clone https://github.com/alx-kap/DiskTree.git
cd DiskTree
./install.sh
Heads up

The first time you open the downloaded app, macOS says it can't verify the developer. That's because DiskTree isn't notarized, which requires a paid Apple developer account. Right-click the app and choose Open, or click Open Anyway in System Settings › Privacy & Security. The one-line install and building from source both skip this.

Questions.

Still wondering? Open an issue on GitHub.

Is it really free?

Yes. DiskTree is open source under the MIT license. No trial, no subscription, and no "upgrade to delete" button at the end of a scan.

Will it delete things on its own?

Never. It only moves what you pick to the Trash, and Trash & History can put items back until you empty the Trash.

What is "System Data," and can DiskTree shrink it?

Much of what macOS calls System Data lives in your home folder's Library: caches, logs, device backups, Xcode and Simulator files. Scan your home folder and DiskTree shows which of those are taking up room. Space macOS can free by itself, like local snapshots, is shown separately so you're not chasing it.

Does it need Full Disk Access?

No. Without it, macOS keeps a few protected folders (like Mail and Messages data) and the inside of the Trash private. Everything else scans normally, and DiskTree tells you when something couldn't be read.

How is it different from DaisyDisk or GrandPerspective?

DiskTree is a free, open-source alternative that pairs the visual map with guided cleanup and an undo history, and it knows about developer clutter like DerivedData, Simulator caches and node_modules.

Does it work on Intel Macs?

Yes. The download is a universal app that runs natively on Apple silicon and Intel Macs with macOS 14 Sonoma or later.
